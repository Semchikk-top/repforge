# Озвучка Fish Speech (1.6.0, экспериментально)

Готовые подсказки (запись, маршрут, пульсовые зоны) можно озвучивать своим голосом через Fish Speech на ПК.
Всё остальное читает системный голос телефона.

Функция экспериментальная: обмен с настоящим Fish, качество на GTX 1050 и воспроизведение при погашенном экране ещё не проверены. По умолчанию озвучка выключена, поэтому эти пункты не блокируют релиз.

## Как это устроено

- Приложение говорит только со своим сервером. Адрес и ключ Fish хранятся на ПК, телефон видит «ключ задан ••••1234».
- Голос = запись 10–30 секунд + точный текст записи + отметка согласия. Лежит в `data/tts-voices/<id>/` (папка 0700, файлы 0600), не синхронизируется.
- Фразы собираются на ПК (`POST /api/tts/pack`, поток событий), скачиваются в память устройства (Cache Storage в браузере, `Directory.Data/tts` в оболочке). Дальше сеть не нужна.
- На записи: фраза есть в манифесте и файл на месте, значит играет файл. Иначе системный голос, без ожидания и без сети.
- Кеш на ПК: `data/tts-cache/`, предел `WORKOUT_TTS_CACHE_MB` (по умолчанию 500), вытесняются давно не использованные.
- Смена голоса, параметров или формата делает прежний пак устаревшим: он удаляется при следующей подготовке.

## Какие фразы чьи

| Вид | Что | Кто читает |
|---|---|---|
| статические | старт, перестроение, возврат на маршрут, финиш, «Темп в норме», зоны пульса | Fish (готовится заранее) |
| маршрут | стартовая фраза и манёвры на каждом пороге | Fish (готовится при построении маршрута) |
| динамические | километры и темп, половина дистанции, итоги, сход с маршрута с расстоянием, интервалы | всегда системный голос |

Числа уходят в Fish словами («сто двадцать метров», «пять целых две десятых километра»). Порядковые («5-я») остаются цифрами.

## Запуск Fish

Fish должен слушать только `127.0.0.1`, с ключом:

```
python tools/api_server.py --listen 127.0.0.1:8080 --api-key <ключ> ...
```

Файлы `API_FLAGS.txt` и `run_api.sh` Fish в архив приложения не входят, поправь их у себя. На сервере приложения:

```
FISH_SPEECH_URL=http://127.0.0.1:8080      # по умолчанию
FISH_SPEECH_API_KEY=<ключ>                 # или введи во вкладке «Сервер»
WORKOUT_TTS_CACHE_MB=500
```

Нужен `ffmpeg` для MP3, без него файлы остаются в WAV.
