# board: сервис мирового рейтинга

Отдельный публичный сервис для таблицы лидеров «весь мир». Не связан с личным сервером синхронизации (`server/`): другой уровень доверия, другая база, другой адрес.

## Что хранит
Открытый ключ, ник и агрегаты за период (тоннаж, подходы, тренировки, километры; 1ПМ, объём и подходы по стартовым упражнениям). Сами тренировки, даты, заметки и маршруты не приходят вообще.

## Запуск
```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r board/requirements.txt
BOARD_ORIGINS=https://app.example BOARD_DATA_DIR=/var/lib/board python -m board run --port 8800
```
Ставьте за HTTPS-прокси (Caddy, nginx, Cloudflare). За прокси включите `BOARD_TRUST_PROXY=1`, иначе лимиты будут считать адрес прокси. Пример unit: `deploy/board.service`.

Клиент собирается с адресом сервиса: `VITE_BOARD_URL=https://board.example npm run build:public` (для личного сервера: `WORKOUT_BOARD_URL`).

## Настройки (переменные окружения)
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `BOARD_ORIGINS` | пусто | адреса приложения через запятую (CORS) |
| `BOARD_ALLOW_LOCALHOST` | 1 | пускать localhost для разработки; в продакшене поставьте 0 |
| `BOARD_DATA_DIR` | `~/board-data` | где лежит `board.db` |
| `BOARD_TRUST_PROXY` | 0 | брать адрес клиента из `X-Forwarded-For` / `CF-Connecting-IP` |
| `BOARD_BLOCKLIST` | нет | файл запрещённых слов для ников, по слову в строке |
| `BOARD_AUTOHIDE` | 5 | сколько жалоб давних участников скрывают игрока до проверки |
| `BOARD_REPORTER_MIN_AGE_H` | 24 | «давний» участник: не моложе стольких часов |
| `BOARD_JOIN_PER_IP_HOUR` / `BOARD_NEW_PROFILES_PER_IP_DAY` | 20 / 5 | лимиты вступления |
| `BOARD_MAX_PROFILES` | 200000 | потолок участников |

## Модерация
```bash
python -m board stats
python -m board reports          # на кого жаловались
python -m board find Ник
python -m board hide #ab12       # скрыть (тег из таблицы или полный id)
python -m board unhide #ab12
python -m board ban #ab12        # скрыть навсегда, стереть итоги, не пускать обратно
python -m board delete #ab12
```
Веб-админки нет намеренно.

## Что сервис гарантирует и чего нет
- Подпись доказывает, что итоги прислал владелец ключа, и защищает от подмены и повтора. Правдивость цифр она не доказывает: клиент может прислать любые числа, отсекается только физически невозможное. Свести к нулю накрутку без аккаунтов и проверки данных нельзя; сдерживают лимиты, жалобы и ручной бан.
- Один человек может завести несколько ключей: лимиты на адрес это затрудняют, но не исключают.
- Границы недели и месяца берутся из календаря участника; у живущих за границей суток они могут на день отличаться, тогда это отдельная таблица. Клиент запрашивает таблицу своего периода.
- Кэш таблицы 15 секунд, в таблице видны итоги не новее последней отправки участника.

## API (кратко)
`POST /v1/join`, `/v1/submit`, `/v1/leave`, `/v1/report` принимают подписанный JSON; `GET /v1/board`, `/v1/profile/{id}`, `/v1/health` открыты. Форматы совпадают с `src/social/world.ts`; совместимость проверяет `tests/test_board.py` на сообщениях, собранных настоящим клиентом (`scripts/gen-board-fixture.ts`).
