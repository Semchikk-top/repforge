## Название (до 30 символов)

## Краткое описание (до 80 символов)
Дневник тренировок и кардио: офлайн, без рекламы, данные у вас

## Полное описание
repforge — личный дневник силовых и кардиотренировок. Работает офлайн, без рекламы
и без обязательной регистрации. Основные функции доступны сразу после установки.

ЧТО УМЕЕТ
- Силовые тренировки: подходы, веса, повторения, RPE, суперсеты, дроп-сеты.
- Программы и календарь: план на неделю, шаблоны, переносы, история.
- Кардио: бег, ходьба, велосипед, запись GPS-маршрута, темп, пульсовые зоны, экспорт GPX.
- Аналитика: объём, рекорды, прогресс по упражнениям, распределение по группам мышц, недельный разбор.
- Напоминания и таймер отдыха, в том числе при погашенном экране.
- Пульсометр по Bluetooth LE.
- Экспорт и импорт данных: JSON, CSV, GPX, импорт из Hevy и Strong.
- Резервные копии на устройстве.

ПРИВАТНОСТЬ
- Данные тренировок хранятся на телефоне.
- GPS-маршруты и пульс не отправляются в сторонние сервисы.
- Нет рекламных SDK и трекеров.
- Синхронизация работает только с вашим личным сервером, если вы её включите.
- Ассистента можно использовать в локальном режиме, без отправки данных наружу.
- Чат «Рядом» работает напрямую между устройствами и не модерируется сервером.

ДЛЯ ЧЕГО НУЖЕН СЕРВЕР НА ПК
Сервер нужен только для синхронизации между устройствами и для ассистента. Без него
приложение полностью работает офлайн. Инструкция — по ссылке в настройках приложения.

ПОДДЕРЖКА
В настройках есть ссылка на добровольную поддержку разработчика. Это не покупка функций:
без неё приложение работает полностью.

ВАЖНО
Приложение не является медицинским изделием и не заменяет консультацию врача.
Перед интенсивными нагрузками проконсультируйтесь со специалистом. Для части функций
(GPS, сканирование QR) на устройствах без сервисов Google возможны ограничения.

## Что нового
Первый публичный релиз.
- Дневник силовых тренировок, программы и календарь.
- Кардио с записью GPS, темпом и пульсовыми зонами.
- Аналитика, рекорды и недельный разбор.
- Напоминания, таймер отдыха и работа при погашенном экране.
- Синхронизация с личным сервером и экспорт данных.
