# Релей «Рядом»

Маленький WebSocket-сервер: выдаёт код комнаты и пересылает между двумя телефонами только `offer`/`answer` (SDP).
Чат, presence и итоги друзей через него не идут: после обмена телефоны соединяются напрямую (WebRTC), а комната сгорает.

```bash
cd relay && npm install
RELAY_ORIGINS=https://workout.example PORT=8787 HOST=127.0.0.1 npm start
npm test
```

Настройки (переменные окружения):

| Переменная | Назначение |
|---|---|
| `RELAY_ORIGINS` | адреса, откуда раздаётся приложение, через запятую; чужой Origin получает 403 |
| `RELAY_ALLOW_LOCALHOST` | `0` — запретить localhost (по умолчанию разрешён для разработки) |
| `RELAY_TRUST_PROXY` | `1` — брать адрес клиента из `CF-Connecting-IP`/`X-Forwarded-For` (за Cloudflare Tunnel и т.п.) |
| `RELAY_TTL_SEC` | время жизни кода, по умолчанию 600 |
| `PORT`, `HOST` | где слушать (по умолчанию `127.0.0.1:8787`) |

Релей не пишет в журнал SDP и коды комнат, ничего не хранит на диске и держит комнаты только в памяти.
Лимиты с одного адреса: 10 созданий, 20 входов и 8 неверных кодов в минуту. Публиковать нужно по `wss://` (например, через Cloudflare Tunnel).
`GET /health` отвечает `ok`.
