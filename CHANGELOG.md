# Что менялось

Приложение в стадии альфа: номера идут 0.1, 0.2 и так далее, до 1.0 ещё далеко.

## 0.5.2

### Быстрее запуск
- **Gzip на сервере.** Ответы больше 1 КБ сжимаются на лету: главный JS-чанк по сети уменьшился с 550 до 171 КБ, CSS — с 38 до 7 КБ. SSE ассистента, шрифты и картинки не затрагиваются.
- **Меньше precache.** Из service worker убран устаревший формат `.woff` и неиспользуемые подмножества/веса шрифтов: 987 → 670 КиБ, 43 → 17 файлов. Регистрация SW перенесена на `window.load`, чтобы установка не конкурировала с первым экраном.
- **Меньше стартовой работы.** `ensureSeeds` и `getDeviceId` идут параллельно, синхронизация и мировой рейтинг запускаются в простое после первой отрисовки.

### Проверено
- Lighthouse (mobile, Tailscale, холодный старт): performance **76 → 89–90**, LCP **4,2 → 2,1 с**, TTI **4,5 → 2,4 с**, передача **673 → 268 КиБ**. TBT остался ~390 мс: это работа React над всем бандлом, следующий шаг — code splitting.
- `npm run typecheck`, `npm run build`, `npm test` — 211 тестов; `pytest -q` — 175 тестов (1 новый на gzip статики); браузерные сценарии `tests/ui/run_all.sh` — 8/8.
- Починен нестабильный UI-тест фото: ожидание удаления теперь ждёт завершения асинхронного `liveQuery`, а не первого же пересчёта DOM. `update_test` берёт версию из `package.json`, `assistant_test` — тестовый адрес сервера, а не автоопределённый живой.

## 0.5.1

### Что нового
- **Дублирование тренировки.** На завершённой тренировке в календаре появилась кнопка «Дублировать»: создаётся план на выбранную дату с теми же упражнениями и весами, но без отметок выполнения.
- **«Как в прошлый раз».** В настройках подхода кнопка подставляет вес, повторы и тип из рабочего подхода прошлой тренировки (разминка и RPE не копируются).
- **Календарь активности.** На экране аналитики — тепловая карта за год, как в GitHub: видно регулярность без переключения периодов.
- **Замеры тела:** переключатель 30/90 дней/всё время, отдельный график талии и пунктирная линия тренда на обоих графиках.
- **Экспорт:** CSV со всеми подходами, JSON для Hevy/Strong и CSV замеров тела. Работают в выбранном периоде.
- **Архив программ.** Завершённый цикл можно убрать в архив, не удаляя: он остаётся в истории и возвращается одной кнопкой.

### Проверено
- `npm run typecheck`, `npm run build`, `npm test` — 211 тестов (6 новых на дублирование и экспорт).
- `pytest -q` — 174 теста. Для тестов сервиса рейтинга в `.venv` доставлен `cryptography>=42` (он уже был в `board/requirements.txt`).

## 0.5.0

### Мировой рейтинг
- Новый отдельный сервис `board/` (Python, FastAPI, SQLite): публичная таблица лидеров по неделе, календарному месяцу и всему времени. Метрики: тоннаж, рабочие подходы, тренировки, километры кардио, а также 1ПМ, объём и подходы по каждому стартовому упражнению.
- Участие добровольное: вступление с ником (не настоящим именем) и явным списком того, что уходит. Тренировки, даты, заметки, замеры, фото, маршруты и свои упражнения наружу не уходят. Выход удаляет ник и все итоги с сервиса.
- Личность без паролей: каждый запрос подписан ключом профиля (тот же, что для друзей), повтор и подмена отсекаются. Сервис не доверяет цифрам слепо: невозможное (больше подходов, чем часов, скорость выше 60 км/ч, несходящиеся итоги) отклоняется. Названия упражнений берутся из каталога сервиса, а не из присланного.
- Защита: лимиты по адресу и участнику, лимит новых участников, жалобы с автоскрытием (считаются только жалобы давних участников), модерация из командной строки (`python -m board hide|ban|delete|reports`), список запрещённых слов задаётся владельцем.
- В приложении: «Рейтинги» → «Весь мир»: таблица с медалями, подгрузкой по 50, вашим местом, отметкой друзей, жалобой на участника, сменой ника и выходом. Итоги отправляются сами при запуске, после тренировки и раз в 15 минут.

### Рейтинг друзей
- Метрика «Тренировки», медали для первой тройки, карточка «ваше место»: сколько до следующего и какой отрыв.

### Таймер отдыха
- Пауза и продолжение: остаток замораживается и переживает перезапуск; «±15 с» работает и на паузе. Друзья в комнате не видят бегущий отсчёт, пока вы на паузе.

### Прочее
- Калькулятор блинов: отмечаете, какие блины реально есть в зале (от 0,25 до 50 кг), расчёт идёт только из них.
- Пульс в кардио: средний и максимальный пульс вручную, свой предельный пульс или оценка по возрасту, пульсовые зоны 1–5 с диапазонами. Автоматического считывания с датчика нет.
- CSP: адрес сервиса рейтинга задаётся `WORKOUT_BOARD_URL` (личный сервер) или `VITE_BOARD_URL` (при сборке).
- Исправлен нестабильный тест подписи (иногда падал из-за совпадения символов).

## 0.4.0

### Рядом: комната для тренировки с другом
- Код комнаты (`XXXX-XXXX`, 10 минут), сверка 6-значного кода на обоих экранах, подтверждение входа хостом.
- Прямое соединение между телефонами (WebRTC DataChannel, без STUN/TURN, только локальная сеть); чат, быстрые фразы, «Позвать» (вибрация и звук), presence: упражнение, подход, таймер отдыха. Вес и повторы не передаются.
- Сигнальный релей `relay/` (Node + `ws`): только offer/answer, лимиты, проверка Origin, без журнала SDP.
- Полоса `RoomBar` над навигацией, Wake Lock на время комнаты, комната живёт между экранами.

### Друзья и рейтинги
- Профиль с ключом подписи (Ed25519, запасной ECDSA P-256), ключ неэкспортируемый и только на устройстве.
- Подписанные снимки итогов за неделю, 4 недели и всё время: нагрузка, упражнения (1ПМ, объём, подходы), кардио отдельно.
- Добавление друга по коду со сверкой и отпечатком ключа, повторное соединение обновляет итоги без подтверждений; обмен файлом без сети.
- Таблицы лидеров среди друзей с честными пометками: нет данных, снимок от даты, другой период.
- Права: участие в рейтинге, блокировка (снимки удаляются), удаление друга.
- Новая отметка подхода «Разминка»: не входит в объём, рекорды, прогрессию и рейтинги.

### Прочее
- CSP принимает адрес релея из `WORKOUT_ROOM_RELAY_URL`; `npm run build:public` пишет `_headers` для статического хостинга.
- Тесты: релей (14), клиент (около 190), браузерные `tests/ui/run_room.sh` (две стороны в Chromium).

## 0.3.0
- **RPE и умная подсказка прогрессии.** В параметрах подхода можно отметить усилие (RPE 6–10). Подсказка учитывает RPE (на пределе: не прибавлять; легко: сразу два шага), перерыв больше трёх недель (начать с ~90%) и усталость (повторы падают две тренировки подряд: разгрузка −10%). Причина подсказки показана текстом, рядом кнопка «Спросить ассистента».
- **Программы тренировок.** Цикл из недель с шаблонами по дням недели; «Назначить в календарь» создаёт плановые тренировки, повторное нажатие дубликатов не делает; при удалении программы убираются её ещё не начатые тренировки.
- **Кардио: анализ темпа** (быстрее всего, медленнее всего, негативный сплит, равномерность), **профиль высоты**, **цвет маршрута по темпу**, **сравнение с прошлыми пробежками по тому же маршруту** с наложением пунктиром.
- **Экспорт за период:** резервная копия (JSON), таблица тренировок (CSV для Excel, защищена от формул), все маршруты одним GPX (с зоной приватности).
- **Конфликты синхронизации.** Если правку с этого устройства перезаписала более поздняя с другого, её снимок сохраняется: в настройках можно вернуть свою версию или оставить чужую. На вкладке «Настройки» красный значок.
- **Светлая тема** (тёмная по умолчанию; есть «как в системе»), без мигания при запуске.
- **Напоминание о тренировке по плану** в выбранное время (в приложении и системным уведомлением, пока приложение открыто или свёрнуто).
- **Фото прогресса** (только на устройстве) со сравнением двух фото рядом.
- **Ассистент:** быстрые вопросы («Проанализируй мою неделю» и др.), вопрос из подсказки по упражнению подставляется в поле, диалог можно сохранить в Markdown или скопировать.
- Исправлено: время стояния на месте (светофор) больше не попадает во «время движения» и в темп; упрощение маршрута больше не выбрасывает точки на прямых (из-за этого пропадали высота и цвет по темпу).

## 0.2.0
- **Суперсеты.** Соседние упражнения объединяются в связку (A1, A2…). Отдых запускается только после последнего упражнения связки, а подсказка говорит, что делать дальше.
- **Типы подходов.** Обычный, дроп-сет и rest-pause. После подхода перед дроп-сетом отдыха нет, перед rest-pause только 15 секунд. Эти подходы не влияют на подсказку прогрессии.
- **Заметки к подходу** (техника, самочувствие). Видны под подходом, ассистенту не передаются.
- **Экран «Рекорды»:** вес, 1ПМ, объём подхода, объём за тренировку; сортировка, поиск и фильтр по группе мышц; рекорды бега и ходьбы.
- **Ярлыки на иконке приложения** (Android): «Начать тренировку», «Текущая тренировка», «Рекорды».
- **Индикатор очереди синхронизации** на вкладке «Настройки»: сколько изменений ждёт отправки. Красным он становится только при потере доступа к серверу.
- Ассистент видит суперсеты и типы подходов.
- Исправлено: за прокси с переписанным Host (Tailscale Serve) защита от CSRF блокировала запись; кнопки под подходами переносятся на новую строку.
- Версии пересчитаны в альфа-нумерацию: то, что раньше называлось «1.0», теперь 0.1.
